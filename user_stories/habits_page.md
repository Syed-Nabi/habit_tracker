# User Stories - Habits Page

## Create a New Habit
**Title:**  
_As a user, I want to create a new habit so that I can track it over time._

**Acceptance Criteria:**
1. User can input habit name, description, frequency, and start date.
2. New habit is saved and displayed in the habits list.

**Priority:** High  
**Story Points:** 3

---

## View All Habits
**Title:**  
_As a user, I want to see a list of all my habits, so that I can manage them effectively._

**Acceptance Criteria:**
1. All active habits are listed with their names and descriptions.
2. Option to sort and filter habits by frequency or creation date.

**Priority:** High  
**Story Points:** 3

---

## Mark Habit as Completed
**Title:**  
_As a user, I want to mark a habit as completed for the day, so that my progress is updated._

**Acceptance Criteria:**
1. User can check a habit as completed for a specific date.
2. Progress bar updates accordingly.

**Priority:** High  
**Story Points:** 2
