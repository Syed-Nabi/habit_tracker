# User Stories - Notification Page

## View Notifications
**Title:**  
_As a user, I want to see notifications about my habits, so that I stay informed and motivated._

**Acceptance Criteria:**
1. Notifications are listed with timestamps.
2. Read/unread notifications are visually distinguished.

**Priority:** Medium  
**Story Points:** 2

---

## Receive Reminders
**Title:**  
_As a user, I want to receive reminders for my habits, so that I don’t miss completing them._

**Acceptance Criteria:**
1. Notifications are sent at user-defined times.
2. Notifications include habit name and frequency.

**Priority:** High  
**Story Points:** 3
