# User Stories - Create Labels

## Add Labels to Habits
**Title:**  
_As a user, I want to add custom labels to my habits, so that I can categorize them effectively._

**Acceptance Criteria:**
1. User can create and assign labels to habits.
2. Labels are displayed on the habits list.

**Priority:** Medium  
**Story Points:** 2

---

## Filter Habits by Labels
**Title:**  
_As a user, I want to filter my habits by labels, so that I can focus on specific categories._

**Acceptance Criteria:**
1. User can select one or more labels to filter habits.
2. Filtered habits update dynamically.

**Priority:** High  
**Story Points:** 3
